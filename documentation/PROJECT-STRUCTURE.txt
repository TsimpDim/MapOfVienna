🎯 KEY FEATURES
───────────────────────────────────────────────────────────────────────────────

✅ Anonymous Discussion Threads
   • No registration required
   • Users provide username only
   • Threads organized by Vienna districts (1-23)

✅ Reply System
   • Add replies to threads
   • No editing after posting
   • No deletion capability (immutable)
   • Threaded conversation flow

✅ REST API
   • RESTful endpoints
   • JSON request/response format
   • CORS-enabled for frontend
   • Pagination support
   • District filtering

✅ Responsive UI
   • Clean sidebar interface
   • District selection
   • Thread browsing
   • Real-time date formatting
   • Form validation

✅ Modern Stack
   • Backend: Django 4.2 + DRF
   • Frontend: Angular 19 + Signals
   • Database: SQLite → MySQL/PostgreSQL
   • Deployment: Docker & Docker Compose

🚀 QUICK START
───────────────────────────────────────────────────────────────────────────────

Docker (Recommended):
  $ docker-compose up
  Backend:  http://localhost:8000/api/
  Frontend: http://localhost:4200

Local Development:
  $ cd backend && python manage.py runserver
  $ cd frontend && npm install && npm start

Using Makefile:
  $ make install      # Install dependencies
  $ make dev          # Start locally
  $ make docker-up    # Start with Docker
  $ make clean        # Clean build artifacts

📊 DATA MODELS
───────────────────────────────────────────────────────────────────────────────

Thread
├── id (Primary Key)
├── title (max 255 chars)
├── content (unlimited)
├── author (max 100 chars, anonymous)
├── district_id (1-23)
├── created_at (timestamp)
└── updated_at (timestamp)

Reply
├── id (Primary Key)
├── thread (ForeignKey → Thread)
├── content (unlimited)
├── author (max 100 chars, anonymous)
├── created_at (timestamp)
└── updated_at (timestamp)

🔌 API USAGE
───────────────────────────────────────────────────────────────────────────────

Create Thread:
  POST /api/threads/
  {
    "title": "Discussion title",
    "content": "Full content here",
    "author": "Your name",
    "district_id": 1
  }

Get Threads:
  GET /api/threads/?district_id=1&page=1

Get Thread with Replies:
  GET /api/threads/1/

Add Reply:
  POST /api/threads/1/add_reply/
  {
    "content": "Reply content",
    "author": "Your name"
  }
